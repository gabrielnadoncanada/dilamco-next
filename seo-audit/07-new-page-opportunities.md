# 07 — Opportunités de nouvelles pages

> Mots-clés commerciaux/transactionnels avec volume réel (DataForSEO, Canada) **non couverts** ou mal couverts par une page dédiée. Chaque opportunité est validée par la donnée avant recommandation.

## Priorité 1 — gains rapides, fort volume/faisabilité

### 1. Vanité 48 pouces — `/boutique/vanites/48-pouces`
- **Mot-clé** : vanité 48 pouces — **590/mois**, transactionnel, HIGH (mais dimension précise = longue traîne atteignable).
- **Intention** : achat d'une vanité double/large format.
- **Concurrence** : marchands e-commerce (SERP prix). Product schema + prix = ticket d'entrée.
- **Page à créer** : sous-catégorie vanité 48 po (nécessite d'**ajouter le produit** au catalogue — actuellement absent ; le catalogue s'arrête à 30 po).
- **Slug** : `/boutique/vanites/48-pouces` (EN : `/en/shop/bathroom-vanities/48-inch`).
- **Titre** : « Vanité de salle de bain 48 pouces — meuble-lavabo double \| Boutique Dilamco ».
- **Priorité** : Haute. **Justification** : plus gros volume dimension du cluster vanité (590 > 390 pour 24 po > 320 pour 30 po), et le site a déjà les pages 24/30 po → cohérence de gamme + gisement « vanité salle de bain » 14 800.

### 2. Îlot de cuisine sur mesure — section renforcée sur `/espaces/cuisine` (ou page dédiée)
- **Mot-clé** : îlot de cuisine sur mesure — **70/mois, KD 5** (faible difficulté) ; « îlot de cuisine » (générique) 6 600.
- **Intention** : commerciale.
- **Recommandation** : d'abord une **section H2 dédiée** sur `/espaces/cuisine` (« Îlot de cuisine sur mesure »), et si le contenu le justifie, une page `/espaces/cuisine/ilot-sur-mesure`. KD 5 = accessible.
- **Priorité** : Haute (faible effort, faible concurrence).

### 3. Aménagement de sous-sol — optimiser l'existant `/espaces/sous-sol`
- **Mot-clé** : aménagement sous-sol — **260/mois, concurrence LOW**. (Déjà une page — pas une création, mais un quick win sous-exploité.)
- **Sous-thèmes à couvrir dans la page** : cinéma maison (2 400, info), bar de sous-sol, cave à vin (10, KD 42 — faible), bibliothèque.
- **Priorité** : Haute (page existe, concurrence faible).

## Priorité 2 — pages-villes (dupliquer le modèle `/zones/laval`)

### 4. `/zones/rive-sud`
- **Mot-clé** : armoires de cuisine rive-sud — **30/mois** (+ « cuisine sur mesure rive-sud », « vanité sur mesure rive-sud »). Le site rank déjà via `/projets/cuisine/cuisine-sur-mesure-rive-sud`.
- **Justification** : réplique du modèle Laval ; capte le cluster local Rive-Sud/Brossard/Longueuil.
- **Titre** : « Armoires de cuisine sur mesure sur la Rive-Sud \| Dilamco ».

### 5. `/zones/ouest-de-lile` (ou `/zones/pierrefonds`)
- **Mots-clés (GSC réels)** : « armoires cuisine sur mesure pierrefonds » (215 impr, pos 7), « custom kitchen cabinets pierrefonds » (105 impr, pos 3), « rénovation cuisine pierrefonds-roxboro » (136 impr). **Le site touche déjà ces requêtes** sans page-ville dédiée → forte justification.
- **Justification** : c'est le **cœur géographique réel** de Dilamco (mémoire projet : ancrage Pierrefonds/Ouest-de-l'Île). Une page-ville consoliderait des impressions déjà existantes.
- **Titre** : « Armoires de cuisine sur mesure à Pierrefonds et dans l'Ouest-de-l'Île \| Dilamco ».
- **Priorité** : Haute (données GSC prouvent la demande).

## Priorité 3 — extensions de gamme rangement (haut de gamme)

### 6. Bibliothèque sur mesure — `/espaces/bibliotheque` (ou section sous-sol/salon)
- **Mot-clé** : bibliothèque sur mesure — **140/mois**, commercial.
- **Intention** : mobilier intégré salon/bureau/sous-sol haut de gamme — cohérent avec le positionnement « espaces de riches » (mémoire projet `seo-espaces-haut-de-gamme`).
- **Priorité** : Moyenne.

### 7. Bureau / mobilier de bureau sur mesure — `/espaces/bureau`
- **Mot-clé** : bureau sur mesure — **90/mois**, commercial ; « aménagement de bureau » (B2B, via `/espaces/commercial`).
- **Intention** : télétravail (B2C) + bureaux (B2B).
- **Priorité** : Moyenne.
