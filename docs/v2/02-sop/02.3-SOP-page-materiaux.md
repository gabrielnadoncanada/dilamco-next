# 02.3 – SOP PAGE MATÉRIAUX

## Dilamco – Standard Operating Procedure

---

# 1. OBJECTIF DU SOP

Définir la méthode officielle de création d’une page matériaux.

Une page matériaux doit :

- Justifier techniquement la qualité premium
- Nourrir le système rationnel du client
- Répondre aux comparaisons implicites
- Renforcer les pages piliers
- Soutenir le positionnement haut de gamme

Elle ne doit pas être commerciale agressive.

---

# 2. RÔLE STRATÉGIQUE D’UNE PAGE MATÉRIAUX

Une page matériaux sert à :

- Expliquer la différence réelle
- Justifier le prix
- Préparer la discussion budgétaire
- Augmenter la confiance technique

Elle alimente principalement :
Le système rationnel.

---

# 3. STRUCTURE OBLIGATOIRE

---

## SECTION 1 – INTRODUCTION CLAIRE

### Exigences :

- Définir le matériau
- Expliquer son rôle dans une cuisine ou vanité
- Positionner le matériau dans une logique qualité

Exemple :
Pourquoi le bois massif est un choix supérieur pour des armoires haut de gamme.

---

## SECTION 2 – DESCRIPTION TECHNIQUE

Décrire précisément :

- Composition
- Propriétés mécaniques
- Résistance
- Durabilité
- Avantages structurels

Langage :

- Précis
- Clair
- Non exagéré

---

## SECTION 3 – APPLICATION CONCRÈTE CHEZ DILAMCO

Exemple obligatoire :

Structure tiroir :

- Bois massif de bouleau

Fond du tiroir :

- Contreplaqué de bouleau

Expliquer :

- Stabilité dimensionnelle
- Résistance au poids
- Longévité
- Supériorité vs mélamine standard

But :
Relier théorie → réalité produit.

---

## SECTION 4 – COMPARAISON IMPLICITE

Comparer :

- Bois massif vs mélamine
- Contreplaqué vs MDF
- Premium vs standard

Ne jamais attaquer agressivement.
Rester factuel.

---

## SECTION 5 – AVANTAGES POUR LE CLIENT

Traduire technique → bénéfice :

- Meilleure durabilité
- Moins de déformation
- Meilleure tenue dans le temps
- Investissement durable

---

## SECTION 6 – INTÉGRATION VERS PAGES PILIERS

Inclure liens vers :

- /espaces/cuisine
- /espaces/salle-de-bain
- /services/renovation

Objectif :
Transfert d’autorité.

---

## SECTION 7 – FAQ TECHNIQUE

Exemples :

- Quelle est la différence entre MDF et contreplaqué ?
- Le bois massif est-il plus durable ?
- Pourquoi éviter la mélamine bas de gamme ?

Réponses :

- Factuelles
- Structurées
- Sans discours commercial agressif

---

# 4. RÈGLES RÉDACTIONNELLES

Ton :

- Technique
- Éducatif
- Premium
- Précis

À éviter :

- Marketing excessif
- Promesses non mesurables
- Texte générique
- Discours discount

---

# 5. DIFFÉRENCE AVEC PAGE PILIER

| Page Pilier                  | Page Matériaux         |
| ---------------------------- | ---------------------- |
| Convertit                    | Justifie               |
| Émotion + logique + sécurité | Logique principalement |
| CTA fort                     | CTA discret            |
| Argumentaire complet         | Argument technique     |

---

☐ Comparaison implicite incluse

---

# 7. KPI À SURVEILLER

- Temps moyen sur page
- Taux clic vers pages piliers
- Impact sur taux conversion global
- Position SEO sur requêtes techniques

---

# 8. RÈGLE FINALE

Une page matériaux doit :

- Justifier le premium
- Éduquer sans vendre agressivement
- Renforcer la crédibilité technique

Si elle ressemble à une page promotionnelle,
elle est mal conçue.
