# 02.4 – SOP FICHE PROJET

## Dilamco – Standard Operating Procedure

---

# 1. OBJECTIF DU SOP

Définir la méthode officielle de création d’une fiche projet.

Une fiche projet doit :

- Servir de preuve sociale concrète
- Renforcer le positionnement premium
- Capter du SEO local
- Alimenter émotion + crédibilité
- Rediriger vers une page pilier

Elle ne doit pas être une simple galerie photo.

---

# 2. RÔLE STRATÉGIQUE D’UNE FICHE PROJET

Une fiche projet sert à :

- Montrer un résultat réel
- Démontrer maîtrise technique
- Prouver capacité d’exécution
- Activer la projection mentale
- Renforcer autorité locale

Elle alimente :

- Le système émotionnel (désir)
- Le système de sécurité (preuve réelle)

---

# 3. STRUCTURE OBLIGATOIRE

---

## SECTION 1 – HERO LOCALISÉ

### Exigences :

- H1 clair
- Mention type de projet
- Mention localisation précise

Exemple :
Cuisine sur mesure au Plateau-Mont-Royal

Objectif :
Capter requêtes locales.

---

## SECTION 2 – CONTEXTE DU PROJET

Décrire :

- Type de propriété
- Objectif client
- Contraintes initiales
- Budget approximatif (si stratégique)

But :
Humaniser et contextualiser.

---

## SECTION 3 – DÉFIS RENCONTRÉS

Exemples :

- Espace restreint
- Plomberie existante
- Configuration complexe
- Contraintes structurelles

Objectif :
Montrer capacité de résolution.

---

## SECTION 4 – SOLUTION APPORTÉE

Décrire :

- Design choisi
- Matériaux utilisés
- Configuration retenue
- Logique fonctionnelle

Inclure :

- Structure tiroirs bois massif
- Fond contreplaqué bouleau
- Justification des choix

But :
Montrer qualité concrète.

---

## SECTION 5 – RÉSULTAT FINAL

Inclure :

- 4 à 8 photos haute qualité
- Détails de finition
- Éléments différenciants

Toujours privilégier photos réelles.

---

## SECTION 6 – IMPACT POUR LE CLIENT

Décrire :

- Gain d’espace
- Amélioration esthétique
- Fonctionnalité accrue
- Valorisation immobilière

But :
Projeter le lecteur.

---

## SECTION 7 – INTÉGRATION VERS PAGE PILIER

Inclure lien vers :

- /espaces/cuisine
- ou /espaces/salle-de-bain
- ou service associé

Objectif :
Transfert d’autorité vers page de conversion.

---

## SECTION 8 – CTA DISCRET

Exemple :

Vous avez un projet similaire ?
Découvrez notre service de cuisine sur mesure.

Ou :

Obtenez une soumission pour votre projet.

---

# 4. RÈGLES RÉDACTIONNELLES

Ton :

- Authentique
- Structuré
- Factuel
- Premium

À éviter :

- Texte court sans contexte
- Galerie sans explication
- Copier-coller générique
- Manque de localisation

---

# 5. DIFFÉRENCE AVEC PAGE PILIER

| Page Pilier          | Fiche Projet        |
| -------------------- | ------------------- |
| Argumentaire complet | Cas réel            |
| Conversion directe   | Preuve indirecte    |
| Structure persuasive | Structure narrative |
| CTA fort             | CTA discret         |

---

# 6. CHECKLIST AVANT PUBLICATION

☐ Localisation précise mentionnée  
☐ Description contexte  
☐ Défis expliqués  
☐ Matériaux détaillés  
☐ Photos réelles HD  
☐ Lien vers page pilier  
☐ CTA intégré

---

# 7. KPI À SURVEILLER

- Position SEO locale
- Temps moyen sur page
- Taux clic vers page pilier
- Contribution au taux conversion global

---

# 8. RÈGLE FINALE

Une fiche projet doit :

- Prouver
- Rassurer
- Inspirer
- Renforcer la conversion

Si elle ressemble à une simple galerie,
elle ne respecte pas le SOP.
