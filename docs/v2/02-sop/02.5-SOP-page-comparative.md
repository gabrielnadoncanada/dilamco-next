# 02.5 – SOP PAGE COMPARATIF

## Dilamco – Standard Operating Procedure

---

# 1. OBJECTIF DU SOP

Définir la méthode officielle de création d’une page comparative.

Une page comparative doit :

- Capturer une intention de comparaison (MOFU)
- Positionner Dilamco comme catégorie premium
- Justifier le positionnement sans attaquer agressivement
- Rediriger vers une page pilier

Elle ne doit pas être diffamatoire ou agressive.

---

# 2. RÔLE STRATÉGIQUE D’UNE PAGE COMPARATIVE

Une page comparative sert à :

- Intercepter un prospect en phase d’évaluation
- Structurer la comparaison
- Élever le niveau de discussion
- Justifier le prix premium
- Transformer un comparateur en prospect qualifié

Elle alimente :

- Le système rationnel
- Le système de sécurité

---

# 3. STRUCTURE OBLIGATOIRE

---

## SECTION 1 – INTRODUCTION NEUTRE

### Exigences :

- Reconnaître que les deux options existent
- Ne pas attaquer
- Positionner le comparatif comme informatif

Exemple :
Choisir entre une cuisine sur mesure et une solution standard dépend de vos priorités, de votre budget et de vos attentes en matière de durabilité.

---

## SECTION 2 – PRÉSENTATION DES DEUX OPTIONS

Décrire objectivement :

Option A :

- Standardisée
- Modules prédéfinis
- Coût plus bas

Option B :

- Sur mesure
- Fabrication contrôlée
- Matériaux premium

Rester factuel.

---

## SECTION 3 – COMPARAISON STRUCTURÉE

Utiliser un tableau clair :

| Critère          | Standard       | Sur mesure Dilamco                 |
| ---------------- | -------------- | ---------------------------------- |
| Personnalisation | Limitée        | Totale                             |
| Matériaux        | MDF / mélamine | Bois massif + contreplaqué bouleau |
| Durabilité       | Moyenne        | Élevée                             |
| Gestion          | Fragmentée     | Clé en main                        |
| Prix             | Plus bas       | Plus élevé                         |

Ne jamais caricaturer.
Toujours rester crédible.

---

## SECTION 4 – ANALYSE DES DIFFÉRENCES RÉELLES

Développer :

- Structure tiroir (bois massif vs panneaux)
- Fond en contreplaqué vs panneau mince
- Stabilité dans le temps
- Résistance à l’humidité
- Gestion du chantier

Objectif :
Justifier rationnellement le premium.

---

## SECTION 5 – POUR QUI CHAQUE OPTION EST ADAPTÉE

Exemple :

Option standard :

- Budget limité
- Projet temporaire
- Location

Dilamco :

- Résidence principale
- Projet long terme
- Recherche qualité durable
- Budget 30k–60k+

But :
Filtrer naturellement.

---

## SECTION 6 – POSITIONNEMENT FINAL

Conclusion structurée :

Dilamco s’adresse aux clients recherchant :

- Durabilité
- Contrôle qualité
- Gestion complète
- Investissement long terme

---

## SECTION 7 – CTA STRATÉGIQUE

Toujours rediriger vers page pilier.

Exemple :

Découvrez notre service de cuisine sur mesure clé en main.

Ou :

Obtenez une soumission pour un projet durable et maîtrisé.

---

# 4. RÈGLES RÉDACTIONNELLES

Ton :

- Calme
- Structuré
- Factuel
- Premium

À éviter :

- Attaque directe
- Dénigrement
- Ton agressif
- Comparaison malhonnête

---

# 5. DIFFÉRENCE AVEC PAGE PILIER

| Page Pilier                  | Page Comparative        |
| ---------------------------- | ----------------------- |
| Convertit directement        | Éduque et redirige      |
| Émotion + logique + sécurité | Logique dominante       |
| CTA fort                     | CTA orienté redirection |

---

# 6. CHECKLIST AVANT PUBLICATION

☐ Comparaison structurée  
☐ Ton neutre  
☐ Matériaux premium mentionnés  
☐ Tableau comparatif inclus  
☐ CTA vers page pilier  
☐ Aucune attaque agressive

---

# 7. KPI À SURVEILLER

- Position SEO sur requête comparative
- Temps moyen sur page
- Taux clic vers page pilier
- Impact sur conversion globale

---

# 8. RÈGLE FINALE

Une page comparative doit :

- Élever la discussion
- Justifier le premium
- Filtrer les budgets bas
- Renforcer le positionnement

Si elle ressemble à un article de blog générique,
elle ne respecte pas le SOP.
