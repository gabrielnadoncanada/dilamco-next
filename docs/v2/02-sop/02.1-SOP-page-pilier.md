# 02.1 – SOP PAGE PILIER

## Dilamco – Standard Operating Procedure

---

# 1. OBJECTIF DU SOP

Définir la méthode officielle de création d’une page pilier transactionnelle.

Une page pilier doit :

- Cibler une intention BOFU
- Générer des soumissions qualifiées
- Justifier le positionnement premium
- Exploiter l’avantage structurel Dilamco

Pages concernées :

- /espaces/cuisine
- /espaces/salle-de-bain
- /espaces/walk-in
- /espaces/commercial
- /services/renovation

---

# 2. PRÉPARATION AVANT RÉDACTION

## 2.1 Définir le mot-clé principal

Exemples :

- cuisine sur mesure Montréal
- rénovation cuisine clé en main
- vanité salle de bain sur mesure

Règle :
Un seul mot-clé principal par page.

---

## 2.2 Identifier intentions secondaires

Lister 3–5 variantes :

- armoire haut de gamme
- entrepreneur cuisine
- design cuisine sur mesure

---

## 2.3 Définir l’angle stratégique

Choisir :

- Angle produit
- Angle clé en main
- Angle rénovation complète
- Angle premium

Ne jamais mélanger sans hiérarchie.

---

# 3. STRUCTURE OBLIGATOIRE DE LA PAGE

Aucune section ne peut être supprimée.

---

# SECTION 1 – HERO

### Exigences :

- 1 seul H1
- Mot-clé principal intégré
- Mention clé en main
- Localisation si applicable
- CTA visible

### Structure recommandée :

H1 :
[Mot-clé principal] + clé en main + localisation

Sous-titre :
Design + fabrication + installation + rénovation complète.

CTA :
Obtenir une soumission gratuite.

---

# SECTION 2 – DIFFÉRENCIATION STRUCTURELLE

Objectif :
Montrer pourquoi Dilamco est différent.

Inclure :

- Entrepôt Montréal
- Relation exclusive usine
- Contrôle approvisionnement
- Qualité maîtrisée

Règle :
Ne jamais paraître comme un simple détaillant.

---

# SECTION 3 – PROCESSUS CLÉ EN MAIN

Décrire 4–5 étapes :

1. Conception
2. Sélection matériaux
3. Fabrication
4. Coordination chantier
5. Installation

Message central :
Un seul responsable du début à la fin.

---

# SECTION 4 – RÉALISATIONS

Minimum :

- 3 photos réelles
- Description courte de chaque projet
- Mention localisation
- Lien vers section projets

---

# SECTION 5 – MATÉRIAUX PREMIUM

Obligatoire :

Inclure détail technique concret.

Exemple :

Structure tiroir :

- Bois massif de bouleau

Fond :

- Contreplaqué de bouleau

Expliquer :

- Durabilité
- Résistance
- Stabilité dimensionnelle
- Supériorité vs mélamine

Objectif :
Justifier le prix.

---

# SECTION 6 – PROJETS MIS EN AVANT

- Sélectionner 2 projets phares
- Mentionner ville
- Lien interne vers fiches projets

---

# SECTION 7 – FAQ STRATÉGIQUE

Minimum 4 questions :

- Quel est le prix ?
- Différence vs IKEA ?
- Délais ?
- Gestion complète ?

Réponses :

- Claires
- Rassurantes
- Orientées solution

---

# SECTION 8 – CTA FINAL

Formulation recommandée :

Obtenez une soumission claire et détaillée pour votre projet.

CTA visible + rassurant.

---

# 4. RÈGLES RÉDACTIONNELLES

Ton :

- Premium
- Maîtrise
- Confiance
- Professionnel

À éviter :

- Langage discount
- Promesse exagérée
- Texte générique
- Copie répétée sur plusieurs pages

---

# 5. CHECKLIST AVANT PUBLICATION

☐ H1 unique  
☐ Mot-clé principal intégré naturellement  
☐ Avantage structurel mentionné  
☐ Matériaux premium détaillés  
☐ 3 CTA minimum  
☐ Liens internes vers services et projets  
☐ FAQ incluse  
☐ Photos réelles uniquement

---

# 6. KPI À SURVEILLER APRÈS PUBLICATION

- Position Google mot-clé principal
- Taux conversion page
- Temps moyen sur page
- Budget moyen lead généré

---

# 7. RÈGLE FINALE

Une page pilier doit pouvoir :

- Convertir sans publicité
- Filtrer les budgets faibles
- Justifier le positionnement premium
- Représenter l’entreprise sans dilution

Si elle ne peut pas faire cela,
elle n’est pas conforme au SOP.
