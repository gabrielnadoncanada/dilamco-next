# 03.2 – PAGES PILIERS

## Dilamco – Stratégie & Positionnement des Pages de Conversion

---

# 1. OBJECTIF DU DOCUMENT

Définir :

- Le rôle stratégique des pages piliers
- Leur périmètre sémantique
- Leur hiérarchie interne
- Leur relation avec le reste du site
- Leur rôle dans la génération de revenus

Les pages piliers sont le centre du système marketing.

---

# 2. DÉFINITION D’UNE PAGE PILIER

Une page pilier est :

- Une page transactionnelle principale
- Optimisée pour une intention BOFU
- Conçue pour convertir directement
- Alimentée par toutes les autres pages

Elle doit pouvoir générer des soumissions sans support externe.

---

# 4. PÉRIMÈTRE SÉMANTIQUE

Chaque page pilier doit :

- Cibler une intention principale unique
- Éviter la duplication avec une autre page pilier
- Intégrer variantes naturelles
- Ne pas cannibaliser une autre page

Exemple :

La page Cuisine ne doit pas se positionner
comme page principale pour "walk-in sur mesure".

---

# 5. RELATION AVEC LES AUTRES SECTIONS

Les pages piliers sont alimentées par :

- Guides → trafic informatif
- Comparatifs → intention intermédiaire
- Matériaux → justification technique
- Projets → preuve sociale
- Services → rassurance

Flux d’autorité :

Toutes les pages secondaires pointent vers les piliers.

---

# 6. STRUCTURE PSYCHOLOGIQUE OBLIGATOIRE

Une page pilier doit activer :

1. Attention
2. Différenciation
3. Désir
4. Justification
5. Sécurité
6. Conversion

Si une de ces étapes est absente,
la page est incomplète.

---

# 7. INDICATEURS DE PERFORMANCE SPÉCIFIQUES

Pour chaque page pilier :

- Position Google mot-clé principal
- Taux conversion
- Temps moyen sur page
- Budget moyen des leads générés
- Taux transformation en contrat

---

# 8. RÈGLES NON NÉGOCIABLES

1. Une page pilier = un mot-clé principal.
2. Aucune dilution discount.
3. Toujours intégrer avantage structurel.
4. Toujours intégrer matériaux premium.
5. Toujours inclure CTA multiples.

---

# 9. OBJECTIF STRATÉGIQUE FINAL

Les pages piliers doivent devenir :

- Des actifs numériques générateurs de revenus
- Des arguments de vente autonomes
- Des filtres à budgets faibles
- Des moteurs de croissance long terme

---

# 10. RÈGLE FINALE

Si une page pilier ne peut pas :

- Convertir seule
- Justifier le premium
- Représenter Dilamco intégralement

Elle doit être retravaillée.
