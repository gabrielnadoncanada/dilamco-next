# 03.5 – COMPARATIFS

## Dilamco – Stratégie SEO & Positionnement des Pages Comparatives

---

# 1. OBJECTIF DU DOCUMENT

Définir le rôle stratégique de la section /comparatifs dans l’écosystème marketing Dilamco.

Les pages comparatives doivent :

- Capter l’intention d’évaluation (MOFU)
- Structurer la comparaison de manière crédible
- Justifier le positionnement premium
- Rediriger vers les pages piliers
- Filtrer les budgets incompatibles

---

# 2. POSITIONNEMENT STRATÉGIQUE DES COMPARATIFS

Les comparatifs interviennent à un moment précis du parcours client :

Le prospect hésite.
Il compare.
Il cherche validation rationnelle.

La page comparative doit :

- Élever le niveau de réflexion
- Mettre en lumière les différences réelles
- Orienter vers la catégorie premium

Elle ne doit pas attaquer.
Elle doit structurer.

---

# 3. LISTE OFFICIELLE DES COMPARATIFS PRIORITAIRES

---

## 3.1 /comparatifs/cuisine-sur-mesure-vs-ikea

Cible :

- Recherches comparatives directes
- Clients sensibles au prix mais ouverts à la qualité

Objectif :

- Montrer différence structurelle
- Justifier matériaux
- Filtrer les budgets bas

---

## 3.2 /comparatifs/cuisine-sur-mesure-vs-home-depot

Cible :

- Comparaison grande surface vs sur mesure

Objectif :

- Mettre en avant fabrication contrôlée
- Souligner gestion clé en main

---

## 3.3 /comparatifs/cuisiniste-vs-entrepreneur-general

Cible :

- Clients confus sur modèle d’affaires

Objectif :

- Clarifier rôle coordination
- Positionner Dilamco comme solution structurée

---

## 3.4 Comparatifs techniques

Exemples :

- bois massif vs MDF
- contreplaqué vs mélamine
- sur mesure vs modules standards

Objectif :

- Capturer intention technique
- Alimenter pages matériaux

---

# 4. RÔLE DANS L’ARCHITECTURE

Flux stratégique :

Comparatif → Page pilier

Toujours.

Jamais l’inverse comme logique dominante.

---

# 5. PÉRIMÈTRE SÉMANTIQUE

Chaque page comparative doit :

- Cibler une requête comparative précise
- Éviter la duplication avec pages matériaux
- Éviter cannibalisation avec pages piliers
- Rester dans un angle structuré

Exemple :

La page “Cuisine sur mesure Montréal”
ne doit pas devenir un comparatif déguisé.

---

# 6. IMPACT PSYCHOLOGIQUE

Une page comparative agit sur :

- Le système rationnel
- La sécurité
- La justification du prix

Elle réduit :

- L’objection budgétaire
- L’incertitude
- Le risque perçu

---

# 7. STRATÉGIE DE FILTRAGE

Les comparatifs doivent :

- Montrer que chaque option a son contexte
- Expliquer pour qui chaque solution est adaptée
- Orienter naturellement vers le premium

Exemple :

Option standard :
Projet temporaire, budget limité.

Dilamco :
Résidence principale, projet durable.

---

# 8. INDICATEURS DE PERFORMANCE

- Position SEO requêtes comparatives
- Temps moyen sur page
- Taux clic vers page pilier
- Impact indirect sur conversion globale
- Budget moyen des leads issus comparatifs

---

# 9. ERREURS À ÉVITER

- Ton agressif
- Attaque directe de concurrents
- Comparaison malhonnête
- Argumentation émotionnelle excessive
- Sur-optimisation SEO

---

# 10. OBJECTIF LONG TERME

Construire une domination sur :

- Requêtes comparatives locales
- Requêtes comparatives nationales
- Requêtes techniques

Faire des comparatifs un levier de qualification avancée.

---

# 11. RÈGLE FINALE

Une page comparative doit :

Éduquer.
Structurer.
Filtrer.
Rediriger.

Si elle ressemble à une page promotionnelle déguisée,
elle perd sa crédibilité.
