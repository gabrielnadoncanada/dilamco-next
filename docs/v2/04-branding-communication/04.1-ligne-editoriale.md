# 04.1 – LIGNE ÉDITORIALE

## Dilamco – Charte rédactionnelle officielle

---

# 1. OBJECTIF DU DOCUMENT

Définir la ligne éditoriale officielle de Dilamco.

Ce document encadre :

- Le ton
- Le vocabulaire
- Le style rédactionnel
- Le niveau de technicité
- Les éléments à éviter

Il garantit la cohérence entre :

Positionnement premium

- Réalité opérationnelle
- Expérience client

  ***

# 2. POSITIONNEMENT À TRADUIRE DANS LE TEXTE

Dilamco est :

- Structuré
- Maîtrisé
- Technique
- Premium
- Stable
- Professionnel

Dilamco n’est pas :

- Discount
- Agressif commercialement
- Sensationaliste
- Improvisé
- Familier excessif

---

# 3. TON OFFICIEL

Le ton doit être :

- Professionnel
- Confiant
- Structuré
- Calme
- Factuel
- Premium

Le texte doit donner l’impression :

“Cette entreprise maîtrise son sujet.”

---

# 4. STYLE RÉDACTIONNEL

---

## 4.1 Clarté

- Phrases structurées
- Pas de jargon inutile
- Explications précises
- Paragraphes aérés

---

## 4.2 Autorité technique

Intégrer :

- Détails matériaux
- Explications concrètes
- Processus clair
- Raisonnement structuré

Toujours relier :

Caractéristique → Bénéfice client

---

## 4.3 Sobriété

Éviter :

- Superlatifs excessifs
- Promesses absolues
- Marketing hyperbolique
- Exagérations non vérifiables

Exemple à éviter :

“La meilleure cuisine au Québec.”

Préférer :

“Une cuisine sur mesure conçue pour durer.”

---

# 5. VOCABULAIRE AUTORISÉ

Mots alignés avec le positionnement :

- Sur mesure
- Durable
- Maîtrisé
- Contrôlé
- Structuré
- Premium
- Qualité
- Fabrication
- Coordination
- Gestion complète
- Approche clé en main

---

# 6. VOCABULAIRE À ÉVITER

- Pas cher
- Rabais
- Promotion massive
- Meilleur prix garanti
- Solution économique
- Rapide et facile
- Sans effort
- Incroyable

Ces termes diluent le premium.

---

# 7. NIVEAU DE TECHNICITÉ

Adapter selon la page :

Page pilier :

- Équilibre émotion + technique

Page matériaux :

- Technique plus détaillée

Guide :

- Pédagogique

Comparatif :

- Structuré et rationnel

Fiche projet :

- Narratif + factuel

---

# 8. STRUCTURE DES ARGUMENTS

Toujours suivre :

1. Contexte
2. Problématique
3. Solution
4. Justification
5. Bénéfice

Ne jamais empiler des arguments sans structure.

---

# 9. COHÉRENCE AVEC LA RÉALITÉ

Chaque promesse doit :

- Être vérifiable
- Être opérationnellement vraie
- Être soutenue par des preuves

Le marketing ne doit jamais dépasser la capacité réelle.

---

# 10. OBJECTIF GLOBAL DE LA LIGNE ÉDITORIALE

Créer une perception constante :

- Entreprise structurée
- Contrôle qualité réel
- Maîtrise de la chaîne d’approvisionnement
- Solution durable

Chaque texte doit renforcer cette perception.

---

# 11. RÈGLE FINALE

Si un texte semble :

- Trop promotionnel
- Trop agressif
- Trop générique
- Trop discount

Il ne respecte pas la ligne éditoriale.

La cohérence de ton est un actif stratégique.
